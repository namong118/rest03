# 01. 경제 교육 사이트 초기 구축

작업일: 2026-06-09

## 목표

경제 동영상 콘텐츠를 제공하는 경제 교육 회사 사이트를 React 템플릿으로 구축한다.  
aebonlee/rest03(건설사 템플릿)의 구조를 참고하여 경제 교육 브랜드 "ECONLAB(이콘랩)"에 맞게 전면 재설계한다.

## 참고 소스

- 참고 리포지토리: `aebonlee/rest03` (건설사 홈페이지 템플릿)
- 배포 타깃: `namong118/rest03` → `namong118.github.io/rest03/`

## 기술 선택

| 항목 | 선택 |
|------|------|
| 프레임워크 | React 18 + Vite 5 |
| 스타일 | Tailwind CSS 3 (class-based dark mode) |
| 라우팅 | React Router 6 — HashRouter (GitHub Pages 호환) |
| 배포 | GitHub Actions → GitHub Pages |
| 폰트 | Pretendard (CDN) |

## 컬러 팔레트 (5색)

화이트 배경에 파스텔 포인트 컬러 + 다크모드 대응 네이비 구성.

| 이름 | 기본값 | 역할 |
|------|--------|------|
| `brand` | `#4DBBDB` | 파스텔 스카이블루 — 주 브랜드 |
| `sage` | `#3CBFA6` | 세이지 민트 — 보조 컬러 |
| `iris` | `#8B78F0` | 라벤더 — 악센트 |
| `sol` | `#FFA421` | 웜 피치/앰버 — 하이라이트 |
| `ink` | `#0F2D50` | 딥 네이비 — 다크모드 배경·텍스트 |

## 다크모드 / 라이트모드

- Tailwind `darkMode: 'class'` 방식
- `<html>` 요소에 `dark` 클래스 토글
- `localStorage('econlab-dark-mode')`에 사용자 선택 영구 저장
- 최초 방문 시 OS 시스템 테마(`prefers-color-scheme`) 자동 감지
- 헤더 우측 ☀/☾ 버튼 및 모바일 메뉴 하단 버튼으로 토글

## 구현 범위

### 공통 컴포넌트

| 컴포넌트 | 내용 |
|----------|------|
| `Header` | sticky, 스크롤 시 blur 효과, 데스크탑 드롭다운 메뉴, 모바일 슬라이드 패널(아코디언), 다크모드 토글 |
| `Footer` | 회사 정보·연락처, SNS 링크, 개인정보 정책 링크, 다크 하단 바 |
| `ScrollToTop` | 라우트 전환 시 스크롤 최상단 이동 |
| `ScrollToTopButton` | 300px 스크롤 후 우하단 플로팅 버튼 노출 |
| `VideoCard` | YouTube 썸네일+클릭 재생(실제 ID) / 카테고리별 그라데이션 플레이스홀더(DEMO ID) 자동 분기 |

### 페이지

| 페이지 | 경로 | 주요 섹션 |
|--------|------|-----------|
| 홈 | `/` | 히어로(그라데이션+통계카드), 통계바(4개), 카테고리 카드(2×3), 최신 영상 6개, 회사 소개 티저 |
| 동영상 | `/videos/:category` | 카테고리 탭바(수평 스크롤), 2열 그리드, 6개/페이지 페이지네이션 |
| 회사소개 | `/about/:tab` | 소개·미션비전·강사소개 탭 |
| 기타 | `/support` `/terms` `/privacy` | 준비중 SimplePage |

### 동영상 페이지 상세

- **카테고리 6종**: 전체 / 경제 기초 / 경제 용어 / 투자·자산관리 / 시사 경제 / 금융
- **그리드**: `grid-cols-1 sm:grid-cols-2` → 모바일 1열, 태블릿+ 2열
- **페이지네이션**: 이전/다음 버튼 + 페이지 번호(±2 범위, 생략부호 처리)
- **카테고리 전환** 시 자동으로 1페이지로 리셋
- **빈 카테고리** 공백 상태(Empty state) UI 포함

### 데이터 구조 (`src/data/site.js`)

- `company` — 회사명, 태그라인, 연락처, 통계, 푸터 링크
- `nav` — GNB 3개 대메뉴 + 하위 메뉴
- `videoCategories` — 6개 카테고리 (key / label / icon / desc / colorClass)
- `videos` — 26개 데모 영상 (id / title / category / youtubeId / desc / duration / date)
  - `youtubeId`를 실제 YouTube 영상 ID로 교체하면 즉시 적용

## YouTube 영상 교체 방법

`src/data/site.js`의 videos 배열에서 각 항목의 `youtubeId` 값을 실제 YouTube 영상 ID로 교체.

```js
// 예시: https://www.youtube.com/watch?v=ABC123xyz
{ id: 1, title: 'GDP란 무엇인가?', youtubeId: 'ABC123xyz', ... }
```

- 공개 영상: 그대로 사용
- 링크 공개(Unlisted) 영상: YouTube에서 "링크가 있는 사람 공개" 설정 후 ID 사용
- 비공개 영상: embed 불가 — 반드시 공개 또는 링크 공개로 설정 필요

## 모바일 최적화 포인트

- 헤더: 햄버거 → 우측 슬라이드 패널 (`85vw, max-w-sm`)
- 카테고리 탭바: `overflow-x-auto` 수평 스크롤
- 영상 그리드: 1열(모바일) → 2열(sm 이상)
- Hero 통계 카드: 데스크탑만 노출, 모바일은 StatsBar 섹션으로 표시
- 모든 버튼: `active:scale-95` 터치 피드백
